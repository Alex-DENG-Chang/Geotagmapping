# 🗺️ GeoTag Mapping & Footprint Visualizer

> *Transform your GPX tracks and digital photo metadata into interactive, visually stunning geotagged maps.*

**GeoTag Mapping** is an Python-based tool designed to extract, process, and map your digital photo geotags and GPX movement data. Featuring an ETL data pipeline and a newly added **GUI with Real-Time Preview**, it allows you to effortlessly render global travel footprints, dot clouds, and density heatmaps.
